# 🇩🇪 Deutsch Lernen — German Flashcard App

## Setup

1. Install dependencies
   npm install

2. Edit .env — fill in your values:
   - MONGODB_URI  → your MongoDB connection string
   - JWT_SECRET   → any long random string
   - ANTHROPIC_API_KEY → from https://console.anthropic.com

3. Start
   npm start

4. Open http://localhost:3000

## MongoDB Atlas (cloud)
Replace MONGODB_URI in .env with:
mongodb+srv://<user>:<password>@cluster0.xxxxx.mongodb.net/deutsch_lernen

## Keyboard shortcuts (Flashcards tab)
← →   Navigate cards
Space  Flip card
